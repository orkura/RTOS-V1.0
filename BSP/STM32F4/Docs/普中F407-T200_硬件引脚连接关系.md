# 普中 F407 定通 T200 开发板硬件引脚连接关系

## 资料范围与使用约定

- 主控：`U1 - STM32F407ZGT6`。
- 原始依据：[普中F407-定通-T200开发板原理图.pdf](普中F407-定通-T200开发板原理图.pdf)（图纸日期：2020-06-05）。
- 本文仅记录原理图中已实际连出的信号；未列出的 MCU GPIO 不表示不能使用，而是未见其连接到板载功能模块。
- 同一 MCU 引脚出现多个信号名时，表示板上为复用或功能兼容而共用该引脚。软件只能启用其中互斥的一个功能，不能假设它们可以同时工作。

## 启动、时钟与调试

| MCU 引脚 / 信号 | 连接对象 | 用途与配置提示 |
|---|---|---|
| PH0 / OSC_IN | Y1 8 MHz 晶振 | HSE 外部高速时钟输入。 |
| PH1 / OSC_OUT | Y1 8 MHz 晶振 | HSE 外部高速时钟输出。 |
| PC14 / OSC32_IN | Y2 32.768 kHz 晶振 | LSE / RTC 时钟输入。 |
| PC15 / OSC32_OUT | Y2 32.768 kHz 晶振 | LSE / RTC 时钟输出。 |
| NRST | RESET 按键、JTAG1、LCD RESET 网络 | 外部复位；不要把该网络当普通 GPIO 使用。 |
| BOOT0 | BOOT 跳线、下拉电阻 R11 | 选择系统存储器或用户 Flash 启动。 |
| PB2 / BOOT1 | BOOT 跳线；同时接触摸 `T_MISO` | 启动配置与触摸 SPI 输入复用；正常启动时保持与启动电路兼容。 |
| PA13 / JTMS-SWDIO | JTAG1 pin 7（TMS/SWDIO） | SWD 数据线。 |
| PA14 / JTCK-SWCLK | JTAG1 pin 9（TCK/SWCLK） | SWD 时钟线。 |
| PB3 / JTDO | JTAG1 pin 13（TDO/SWO）；SPI1_SCK | 调试输出与 SPI 时钟复用。 |
| PB4 / JNTRST | JTAG1 pin 3（TRST）；SPI1_MISO | JTAG 复位与 SPI 输入复用。 |
| PA15 / JTDI | JTAG1 pin 5（TDI）；USB_PWR | JTAG 数据输入与 USB Host 电源开关控制复用。 |

## 串行通信、CAN 与 Wi-Fi

| 功能 | MCU 引脚 | 板载器件和对应引脚 / 网络 | 配置提示 |
|---|---|---|---|
| USART1_TX | PA9 | U4 CH340C（USB 转串口）、P4 USART1 | 串口下载、调试日志。 |

| USART2_TX | PA2 | U5 SP3232 的 `U2_TX` 通道；U7 SP3485 `DI`（`RS485_TX`） | RS232 和 RS485 共用 USART2 发送端。 |
| USART2_RX | PA3 | U5 SP3232 的 `U2_RX` 通道；U7 SP3485 `RO`（`RS485_RX`） | RS232 和 RS485 共用 USART2 接收端。 |
| RS485 收发控制 | PG8 | U7 SP3485 `RE` / `DE`（`RS485_RE`）；同时为 NRF_IRQ | 半双工时由软件控制方向；与 NRF24L01 中断共用。 |
| CAN1_RX | PD0 | U8 TJA1040 `RXD`（CAN_RX） | 配置 CAN1 接收。 |
| CAN1_TX | PD1 | U8 TJA1040 `TXD`（CAN_TX） | 配置 CAN1 发送；P7 输出 CANH / CANL。 |
| Wi-Fi TX | PB10 | P3 ESP8266WIFI `URXD`（W_TX） | MCU 向 Wi-Fi 模块发送数据。 |
| Wi-Fi RX | PB11 | P3 ESP8266WIFI `UTXD`（W_RX） | MCU 接收 Wi-Fi 模块数据。 |
| Wi-Fi 状态 / GPIO | PC0 | P3 `GPIO16`（W_LED） | 与 `3D_INT` 共用。 |
| Wi-Fi 控制 / GPIO | PF6 | P3 `GPIO0`（W_KEY） | 启动模式相关脚位，改变电平前确认模块启动需求。 |

## USB 与 I2S 扩展

| 功能 | MCU 引脚 | 网络 | 连接对象 / 说明 |
|---|---|---|---|
| USB OTG FS D- | PA11 | USB_D- | USB1 Slave 与 USB3 Host 的数据路径。 |
| USB OTG FS D+ | PA12 | USB_D+ | USB1 Slave 与 USB3 Host 的数据路径。 |
| USB Host 电源控制 | PA15 | USB_PWR | 控制 MOS1 / TP3 的 USB-A VBUS 供电；与 JTDI 共用。 |
| I2S SDOUT | PC2 | I2S_SDOUT | J3 / J4 扩展音频接口。 |
| I2S SDIN | PC3 | I2S_SDIN | J3 / J4 扩展音频接口。 |
| I2S MCLK | PC6 | I2S_MCLK | 与 DCMI_D0 共用。 |
| I2S LRCK | PB12 | I2S_LRCK | 音频帧同步。 |

> USB Host 与 USB Device 使用同一组 OTG FS 数据线；软件和外接硬件必须保证任一时刻只选择一种角色。I2S、SDIO 与 DCMI 也存在复用，应按实际功能选择对应复用模式。

## 外设初始化前检查清单

1. 根据上表确认目标引脚没有被其他板载模块占用。
2. 使能对应 GPIO 和外设时钟，并选择与表中网络匹配的复用功能。
3. 对 FSMC、RMII、DCMI、SDIO 等高速接口，按器件数据手册和板载时钟配置时序、驱动能力与上拉配置。
4. 对 PB2、PB3、PB4、PA15、PA2、PA7、PA8、PC0、PC6-PC12、PG8、PG9 等复用/共用引脚，先确认启动、调试、通信和扩展模块不会互相影响。
5. 物理连接、供电电平、跳线状态有疑问时，以原理图 PDF 和目标模块数据手册为准。
