RTOS-V1.0 · 构建与运行架构

RT-Thread Nano 多 BSP 固件 · 将“选什么进入镜像”与“镜像如何运行”分为两个视图

2 个可构建 BSP 1 kHz 系统 Tick 32 级线程优先级 ELF · HEX · BIN · MAP

启动链与线程化入口

  • • 启动文件跳入 entry()，随后执行 rtthread_startup()
  • • 板级初始化先建立时钟、Tick、堆与设备注册表
  • • 调度器启动后，main 线程先初始化组件，再调用应用 main()
  • • FinSH 由 INIT_APP_EXPORT 创建独立 shell 线程

稳定接口与可替换边界

  • • 应用经 rt_device_find/open/read/write/control 访问硬件
  • • BSP/*/Ports 把 RT-Thread 设备操作映射到厂商驱动
  • • CPU Port 封装 PendSV 上下文切换与 Cortex-M 差异
  • • 因而切换 BSP 不要求修改 Applications 或公共内核配置

当前配置与适用边界

  • • 已启用：设备框架、FinSH、堆、信号量、邮箱、控制台
  • • 未启用：mutex、event、message queue、软件定时器线程
  • • STM32F4 提供中断接收 UART 与 RTC；CC2538 控制台为轮询 UART
  • • Components/ 当前为空，图中作为未来扩展缝而非现有模块
